# SPORTNOVA

## Descripción

**SPORTNOVA** es una página web de venta de artículos deportivos, diseñada para ofrecer productos para diferentes disciplinas como fútbol, básquet, running, ciclismo, gimnasio y boxeo.

La página presenta un catálogo de productos con imágenes, precios, especificaciones y un botón para iniciar el proceso de compra. También incluye información sobre los beneficios de la tienda, una galería deportiva y una sección de contacto mediante WhatsApp.

## Características principales

- Página de inicio con presentación de SPORTNOVA.
- Menú de navegación con las secciones:
  - Inicio
  - Productos
  - Beneficios
  - Galería
  - Contacto
- Catálogo de productos deportivos.
- Tarjetas de productos con:
  - Imagen.
  - Nombre.
  - Descripción.
  - Precio en bolivianos (Bs.).
  - Especificaciones.
  - Botón **Comprar Ahora**.
- Formulario de compra.
- Selección de método de pago:
  - Tarjeta de crédito.
  - Tarjeta de débito.
  - Transferencia bancaria.
  - QR.
- Confirmación de compra mediante WhatsApp.
- Sección de beneficios con envíos, calidad, pago seguro y atención al cliente.
- Galería de imágenes deportivas.
- Diseño adaptable para dispositivos móviles.

## Productos incluidos

La página contiene productos como:

- Balón Profesional de Fútbol.
- Zapatillas Running Elite.
- Balón de básquet.
- Bicicleta Deportiva XT.
- Guantes de gimnasio con muñequera.
- Polera deportiva transpirable.
- Guantes de arquero profesional con varillas.
- Guantes de boxeo profesional de cuero.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño, colores, tarjetas, botones, animaciones y adaptación a pantallas pequeñas.
- **JavaScript:** funcionamiento de las ventanas de compra, interacción con los productos y enlace de confirmación mediante WhatsApp.
- **SVG:** creación del logotipo mostrado en la portada.
- **WhatsApp:** utilizado para facilitar la comunicación y confirmación de compras.

## Estructura del proyecto

Actualmente, el proyecto está desarrollado principalmente en un único archivo HTML:

```text
SPORTNOVA/
└── pagina web jhon.html
```

El archivo contiene la estructura HTML, los estilos CSS y el código JavaScript necesario para las funciones principales.

## Cómo ejecutar la página

1. Descarga o copia el archivo `pagina web jhon.html`.
2. Ábrelo con un navegador web como Google Chrome, Microsoft Edge o Mozilla Firefox.
3. La página se cargará directamente sin necesidad de instalar un servidor para la versión actual.

## Proceso de compra

1. El usuario selecciona un producto.
2. Presiona **Comprar Ahora**.
3. Se abre un formulario de compra.
4. Se muestran el producto y su precio.
5. El usuario puede ingresar sus datos, dirección, cantidad y método de pago.
6. La confirmación se realiza mediante WhatsApp.
